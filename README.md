# Кабинет министра — прототип

Кликабельный desktop-прототип аналитического кабинета.

## Технологии

Replit должен создать проект на:
- React
- TypeScript
- Vite

## Правила

- использовать токены из design-system;
- создавать переиспользуемые компоненты;
- не добавлять случайные цвета и отступы;
- не использовать inline styles;
- не использовать скриншот как фон;
- данные должны быть моковыми;
- бэкенд и авторизация не нужны.
